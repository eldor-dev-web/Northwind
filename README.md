# Northwind Full-Stack E-Commerce Application

A modern, full-stack e-commerce web application inspired by Northwind Supply, featuring a robust API backend and a responsive Vite-powered frontend.

---

## 🚀 Features

* **Product Catalog:** Browse curated hardware and workspace tools with detailed categories.
* **Shopping Cart & Checkout:** Manage cart items seamlessly and proceed securely with Clerk authentication.
* **Order Management:** Track orders and access order-scoped chat and support channels.
* **Modern UI/UX:** Clean, dark-themed responsive design built with Tailwind CSS and DaisyUI.
* **Authentication:** Secure user management integrated via Clerk.

---

## 🛠 Tech Stack

### Frontend
* **Framework:** React (Vite)
* **Styling:** Tailwind CSS, DaisyUI
* **Authentication:** Clerk React

### Backend
* **Runtime:** Node.js, TypeScript
* **ORM/Database:** Drizzle ORM
